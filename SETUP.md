# Getting Started with Claude Blog

Welcome! You've forked Claude Blog. Here's what to do next.

## Option 1: AI-Assisted Setup (Recommended)

The easiest way to get started is to use Claude Code to guide you through setup. **You don't need to know anything technical—Claude handles it all.**

### Steps:

1. **Clone your fork** to your machine:
   ```bash
   git clone https://github.com/YOUR_USERNAME/blog
   cd blog
   ```

2. **Open in Claude Code** (or your AI editor with Claude access):
   - Open the `blog` folder
   - Copy the contents of `.claude/AGENT_SETUP.md`
   - Paste it into Claude, then say: "I want to set up my blog. Help me."

3. **Follow Claude's guidance**. You'll be asked for:
   - Your blog name and tagline
   - Your name and email
   - Categories for your content
   - Topic for your first post

4. **Claude handles everything else**:
   - Creates the right files
   - Customizes metadata
   - Sets up your categories and author info
   - Writes your first post
   - Runs a preview so you can see it
   - Pushes to GitHub
   - Deploys to GitHub Pages

5. **Your blog is live!** Within 30 seconds, it's live at `https://[your-username].github.io/blog/`

## Option 2: Manual Setup

If you prefer to set everything up yourself, see [Contributing Guide](.github/CONTRIBUTING.md).

## Quick Reference

Once your blog is set up, here's the workflow:

- **Write a new post**: Tell Claude "Write a post about [topic]"
- **Add a category**: Tell Claude "Add a category for [name]"
- **Customize design**: Tell Claude "Change the colors to [description]"

Everything else (file management, git, deployment) is automated.
